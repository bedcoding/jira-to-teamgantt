# Jira to TeamGantt

Jira 이슈와 TeamGantt 작업을 한 곳에서 비교해 누락을 찾고, TeamGantt에 빠진 작업을 한 번에 등록하는 Chrome 확장 프로그램입니다.

## 기능

- **Jira 수집**: JQL 조건에 맞는 이슈를 전량 수집. 키, 제목, 상태, 담당자, 보고자, 우선순위, 해결, 생성/업데이트 시각, 마감일, 레이블을 저장
- **TeamGantt 수집**: 열어둔 TeamGantt 탭의 인증 정보로 프로젝트 작업을 가져옴. 본인 작업만 필터링 가능. TeamGantt에서 지운 작업은 재수집 시 로컬에서도 정리됨
- **비교**: 두 출처를 Jira 키 기준으로 매칭해 `매칭` / `Jira만` / `TeamGantt 고아(키 있음/없음)` 로 분류
- **그룹에 일괄 등록**: TeamGantt에만 없는 작업을 체크해 원하는 그룹에 한 번에 생성(+담당자 자동 할당). 이미 등록한 항목은 중복 생성되지 않음
- **수동 동기화**: 단축키(`Cmd+Shift+X` / `Ctrl+Shift+X`)로 TeamGantt 활성 입력창에 한 건씩 주입하는 기존 방식도 그대로 제공
- **추출**: 선택한 기간의 항목을 `[KEY] 제목` 형식 텍스트로 모아 복사
- **백업/복원**: 모든 데이터·설정을 JSON 파일로 저장하고 미리보기 후 복원

## 설치

1. 이 저장소를 clone 하거나 ZIP 다운로드 후 압축 해제
2. Chrome 주소창에 `chrome://extensions` 입력
3. 우측 상단 **개발자 모드** 켜기
4. **압축해제된 확장 프로그램을 로드합니다** 클릭
5. `jira-to-teamgantt` 폴더 선택

툴바 아이콘을 누르면 **사이드패널**이 열립니다.

> 코드를 수정한 뒤 반영하는 방법은 파일 종류마다 다릅니다.
> `popup/`·`lib/` → 사이드패널을 닫았다 열기 / `content/`·`background/`·`manifest.json` → `chrome://extensions` 에서 ↻ 새로고침 (콘텐트 스크립트는 대상 탭도 F5)

## 탭별 사용법

### 지라

1. **경로**: 본인 Atlassian 도메인 (예: `mycompany.atlassian.net`)
2. **기간**: 단위 토글(일/주/월/분기/년) 선택 후 `‹ 이전 / 이번 / 다음 ›`으로 이동. JQL의 `updated >= ... AND updated < ...` 가 함께 갱신됨
3. **JQL**: 기본값은 `assignee = currentUser() AND updated >= "..." AND updated < "..." order by updated DESC`. 직접 수정 가능

수집 버튼은 세 가지입니다.

| 버튼 | 방식 | 비고 |
|---|---|---|
| **REST 직통** | Jira REST API(`POST /rest/api/3/search/jql`)를 쿠키 세션으로 직접 호출 | 주력. 전량 수집. 아무 Jira 탭이나 열려 있으면 됨 |
| API 가로채기 | 페이지가 보낸 GraphQL 응답을 가로채 수집 | 안 잡히면 `[검색]`을 다시 실행 |
| DOM 추출 | 화면에 보이는 이슈 행을 직접 읽음 | 가상 스크롤 때문에 화면 밖 행은 빠짐 |

`REST 직통`은 `nextPageToken`을 따라가며 끝까지 받습니다. 스낵바에 `N페이지 M건 수신`이 표시되고, 상한에 걸리거나 중간에 실패해 전량이 아니면 사유를 빨간색으로 알립니다.

### 간트

1. **프로젝트** / **사용자**: ⚙️ 버튼 → `API 자동` 탭 → `[API 추출]`. TeamGantt 탭만 열려 있으면 목록을 알아서 가져옵니다 (JSON 복붙은 이제 불필요하며, 필요하면 `JSON 붙여넣기` / `1줄 추가` 탭도 남아 있습니다)
2. 본인 ID를 설정하면 본인이 담당자인 작업만 추려 저장합니다

수집 버튼은 세 가지입니다.

| 버튼 | 방식 | 비고 |
|---|---|---|
| **API 직통** | 열어둔 TG 탭의 토큰으로 `children` API를 직접 호출 | 주력. 새로고침·캐시 대기 불필요. **응답에 없는 작업은 로컬에서 정리** |
| API 가로채기 | 페이지가 보낸 API 응답을 가로채 수집 | 안 잡히면 페이지 새로고침 |
| DOM 추출 | 화면에 보이는 작업 행을 직접 읽음 | 화면 밖 행은 날짜가 빠짐 |

`API 직통`의 정리(prune)는 **로컬 저장소만** 대상입니다. TeamGantt의 데이터는 건드리지 않습니다. 0건이 수집되면 정리를 건너뛰고, 다른 프로젝트에서 수집한 작업도 건드리지 않습니다.

### 비교

상단 검색·날짜 기준·필터 칩으로 목록을 좁힌 뒤, 하위 탭 두 가지 중 하나로 작업합니다.

#### 그룹에 일괄 등록 (기본)

1. 비교 탭에 들어가면 그룹 목록이 자동으로 채워집니다 (TeamGantt 탭이 열려 있을 때). 수동으로 받으려면 `[그룹 불러오기]`
2. 표 왼쪽 체크박스로 등록할 항목 선택
   - **드래그**로 여러 건 한 번에 선택
   - **Shift+클릭**으로 범위 지정
   - 헤더 체크박스로 현재 필터에 보이는 것 전체 선택
3. 넣을 그룹 선택. 자주 쓰는 그룹은 **☆ 즐겨찾기**로 맨 위에 고정
4. `[선택 N건 등록]` → 확인창에서 건수·그룹·처음 5건(날짜 포함)을 확인하고 진행

등록되는 작업은 이름 `[KEY] 요약`, **시작일 = 종료일 = Jira 업데이트일**, 완료 상태면 진행률 100입니다.

이미 처리한 항목은 체크가 잠깁니다. 판정 근거는 셋입니다 — 단축키로 넣은 것 / API로 만든 것 / 직접 넣고 `✓` 표시한 것. 잘못 등록했다면 `✓ 등록 완료` 옆 `×`로 이력을 풀어 다시 넣을 수 있습니다.

#### 수동 동기화

1. TeamGantt 프로젝트 페이지의 새 작업 입력창에 커서를 둠
2. `[동기화 시작]` 후 단축키 → 다음 미매칭 항목이 `[KEY] 제목` 형식으로 주입됨
3. Enter로 확정 (날짜·담당자 보정은 평소처럼)
4. 다시 단축키 → 직전 항목은 큐에서 빠지고 다음 항목이 주입됨

#### 기타

- ⚙️ 버튼은 **키 추출 규칙**(정규식) 편집. TeamGantt 작업 제목에서 Jira 키를 뽑는 규칙입니다
- 키 셀 클릭 → Jira 이슈 새 탭, 제목 셀 클릭 → 클립보드 복사

### 추출

1. **소스**: Jira / TeamGantt 중 선택
2. **기간**: 지라 탭과 동일한 단위 토글 + 이전/이번/다음
3. 결과가 텍스트 영역에 쌓이면 **복사** 버튼으로 클립보드에

### 단축키

- **mac**: `Cmd+Shift+X`
- **그 외**: `Ctrl+Shift+X`

충돌하면 `chrome://extensions/shortcuts` 에서 변경할 수 있습니다.

## 데이터와 네트워크

모든 데이터는 `chrome.storage.local` 에만 저장되고, **개발자 서버는 존재하지 않습니다.** 백업/복원도 로컬 JSON 파일 단위입니다.

네트워크 요청은 아래가 전부이며, 모두 사용자가 로그인해 둔 서비스의 공식 API입니다.

| 요청 | 용도 |
|---|---|
| `POST {jira}/rest/api/3/search/jql` | 이슈 검색 (읽기) |
| `GET {jira}/rest/api/3/search` | 위 실패 시 폴백 (읽기) |
| `GET api.teamgantt.com/v1/groups`, `/projects`, `.../children` | 그룹·프로젝트·작업 조회 (읽기) |
| **`POST api.teamgantt.com/v1/tasks`** | **작업 생성 (쓰기)** |
| **`POST api.teamgantt.com/v1/tasks/resources/bulk/create`** | **담당자 할당 (쓰기)** |

쓰기 요청 두 가지는 **`[선택 N건 등록]` 버튼에서만, 확인창을 통과한 뒤에** 실행됩니다. 그 외에는 자동으로 실행되지 않습니다.

**삭제 요청은 없습니다.** 이 확장은 Jira와 TeamGantt의 데이터를 지우지 못합니다. `API 직통` 수집의 "정리" 기능은 로컬 사본만 정돈하는 것입니다.

동작 도메인은 `*.atlassian.net`, `app.teamgantt.com`, `api.teamgantt.com` 세 곳뿐입니다.
